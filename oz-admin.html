共有設定（Google Apps Script）

🔗 GAS Web App URL

下のSTEPに従ってGoogle Apps ScriptのURLを取得し、貼り付けてください。
URLを設定すると、管理画面・子どもページ両方のデータがGoogleスプレッドシートで共有されます。

📋 GASの設定手順
STEP 1 — Googleスプレッドシートを新規作成
sheets.google.com を開き、「空白」で新しいシートを作成。名前は「OZデータ」など何でもOK。
STEP 2 — Apps Scriptを開く
スプレッドシートのメニューから「拡張機能」→「Apps Script」をクリック。
STEP 3 — スクリプトを貼り付ける
左の「コード.gs」を選択して、中身を全部消して下のコードを貼り付けて保存（Ctrl+S）。
STEP 4 — デプロイする
右上の「デプロイ」→「新しいデプロイ」→「ウェブアプリ」を選択。
「次のユーザーとして実行」→「自分」、「アクセスできるユーザー」→「全員」に設定して「デプロイ」。
表示された ウェブアプリのURL をコピー。
STEP 5 — URLを上の欄に貼り付けて「保存」
同じURLを 子どもページ（oz-kids.html）の冒頭 にも貼り付けが必要です（下に説明あり）。
📄 貼り付けるGASコード（クリックでコピー）

          
クリックでコードをコピーできます

        

      

      

        
🧒 子どもページへのURL設定方法

        

          oz-kids.html をテキストエディタで開き、上の方にある以下の行を探して、GAS URLを貼り付けてください：
        

        
const GAS_URL = ''; // ← ここにGAS URLを貼り付け

        

          変更後は oz-kids.html を GitHub Pages に再アップロードしてください。
